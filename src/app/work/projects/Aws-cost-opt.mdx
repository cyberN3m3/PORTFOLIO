## Overview

AWS doesn't warn you about the server you forgot, the disk nobody detached or the logs kept forever. It just bills you. CostPatrol checks for those things every Monday across every enabled region, works out what each one costs, and writes it up as a "ticket" in plain English that a business owner can read without knowing AWS.

This is version 3 of a project I first built in March 2026. Version 1 worked, but it exposed a public API with no login: anyone with the link could run a scan of my account and read the results. It also used hard-coded prices, had 4 checks and no tests. I rebuilt it from the security up and renamed it CostPatrol.

## What it does

- **Checks every enabled region weekly**: 18 regions in about 35 seconds on my own account, with a read-only IAM role.
- **9 kinds of waste**: idle EC2 (stop or downsize), unattached EBS volumes, gp2 volumes that can move to gp3, snapshots older than 90 days, unattached Elastic IPs, idle NAT gateways, idle load balancers, log groups that keep data forever, and S3 buckets with no lifecycle rules.
- **Real prices and the real bill**: EC2 prices from the AWS Price List API for the exact type and region; last month's spend, the trend, the top services and AWS's forecast from Cost Explorer, plus a Savings Plan recommendation. Estimates are labelled as estimates.
- **A ranked report**: every finding gets a monthly saving, an effort and a risk, biggest first. The report is saved as HTML and JSON to a private bucket each week and summarised by email.
- **A dashboard for non-technical owners**: each finding is a ticket ("A server doing nothing"), a receipt adds up what fixing them saves, and you can untick anything you want to keep. **Save as PDF** turns it into a client-ready report. The report is read inside the browser and never uploaded.
- **Client reviews without installing anything**: `scan.py` runs the same scan from a laptop through a cross-account, read-only role locked with an external ID.

## Technologies Used

- **AWS Lambda (Python 3.12) and EventBridge**: the scanner, on a weekly schedule.
- **Cost Explorer and the Price List API**: spend, forecast, Savings Plans and prices.
- **S3 and SNS**: private, encrypted, TLS-only reports that expire after 180 days, and the email summary.
- **CloudFront with Origin Access Control**: HTTPS only, HSTS and a strict Content Security Policy for the dashboard.
- **Terraform**: about 25 resources, with outputs for "run a scan now" and "download the latest report".
- **pytest, moto and GitHub Actions**: 22 tests that fake AWS in memory, plus `terraform fmt`/`validate` and Checkov on every pull request.
- **HTML, CSS and JavaScript**: the dashboard, with no framework and no calls to AWS.

## Challenges and Learnings

The biggest lesson was that "it works" isn't the same as "it's safe to share". Version 1's dashboard called a public `POST /scan` endpoint with open CORS and no authentication, and its URL was hard-coded in the public page. The fix wasn't to add a login: the scanner only needs to run on a schedule, so I removed the API entirely and kept on-demand scans behind my own IAM access (`aws lambda invoke`). The safest API turned out to be no API.

The second lesson was about trust when working in someone else's account. For client reviews I use a cross-account role with read-only permissions and an external ID, which prevents the "confused deputy" problem. I tested it the way a client would: without the external ID the role was refused, and with it, creating a bucket, reading secrets and deleting logs were all denied. The read-only scan still found exactly the same 18 findings, regions, bill and forecast as the full scanner.

Checkov pushed real fixes (an abort-incomplete-uploads lifecycle rule, scoped IAM resources, a response headers policy and HSTS preload). The 24 checks I chose to skip are written next to each resource with the reason, such as no WAF for a static page that has no API.

## Outcome

CostPatrol is something I can run for a client today: a read-only review of every region, a plain-English PDF ranked by what each fix saves, and a short walkthrough call, or a weekly install in their own account with Terraform. Running it costs about $0.16 a month in Cost Explorer API calls; everything else stays inside the free tier at one scan a week.
